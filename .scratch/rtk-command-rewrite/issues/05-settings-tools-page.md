## Comments

- 单开一页的理由（照决策 287 给值守轮开关单开一页的先例）：rtk 不属于任何一个现有页面的主题
  （项目 / 模型 / 阶段 / 技能市场 / 值守轮 / 通知），塞进哪一页都会让那页主题变糊；而且「机器级的命令
  执行设置」这一类后面还会长（出口策略、超时都在这一带），有一个自己的落点比每次蹭别人的页面便宜。
- 粒度是**全局**而非阶段级：rtk 是「这台机器上要不要用这个二进制」的机器事实，不是「这个阶段在干什么」
  的阶段语义——阶段级正是为后者设的（决策 206 的原话）。阶段级还要多付一列迁移 + 三层解析 + 跨语言
  spec 表，收益是今天说不出谁需要。
- 探测失败不拦的理由见票 03 的 Comments（决策 185 + 先开后装是常见顺序）。
