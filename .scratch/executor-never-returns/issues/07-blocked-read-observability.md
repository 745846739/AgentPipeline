# 07: 卡住的读——计数、日志、超阈值落待办

**Spec:** `../spec.md`（Implementation Decisions 第 9 条）

**What to build:** 作为值班经理，我要「有读卡住了」成为一个**能读的数**，而不是静默攒满阻塞池。
背景已裁决：`spawn_blocking` 的闭包被 drop 后**线程仍跑到结束**，泄漏是**显式接受**的——
所以要的是观测，不是掩盖（**不用 `timeout` 假装解决**，它唯一的作用是让请求返回，而那件事票 02 已独立保证；
**不用有界专用池**，满了会把「环境卡住」翻译成「节点失败 → 重试 → 再卡」，把一个可观测的挂起变成一串不可观测的失败重试，
正是这次故障的形状）。

**Blocked by:** 01（节点请求组装的同步文件读挪出运行线程）
