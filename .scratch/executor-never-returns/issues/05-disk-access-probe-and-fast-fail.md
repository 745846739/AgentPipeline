# 05: 完全磁盘访问——每次启动有界探测 + 缺授权快速失败

**Spec:** `../spec.md`（Implementation Decisions 第 6–8 条）

**What to build:** 作为值班经理，我要应用**每次启动**都检查完全磁盘访问权限：有效则**完全静默**，
缺失才引导我去系统设置；真缺授权时，节点**立刻**返回一句可操作的错误，而不是每个都白等 300 秒再失败。
（这次的真因就是这个：未签名 app 重建 → CDHash 变 → 授权失效 → 文稿授权弹窗无人应答 → `open()` 挂 4 小时。）

**Blocked by:** None (can start immediately)

**Status:** done（已实现，决策 302–311；四门 `make check` 全绿）

- [x] 探测**有界**：阻塞池 + 超时，超时即判「未授权」；**不阻塞启动**
- [x] **不能用普通读来探**——`access()` / `stat()` 对受保护路径**同样会阻塞**，那样探测本身就复刻这次 4 小时的形状
- [x] 授权有效时**零输出、零弹窗**（启动检测选「每次」而非「安装时」的理由：授权能否跨重建存活无法离线验证，这个形态对「稳定」「不稳定」两种世界都正确）
- [x] 缺失时打开系统设置对应面板 + 应用内说明
- [x] 授权状态**以值注入**测试（照第五条接缝远端地址替换点的「非类型缝」先例）；
      **显式记录「不新造 `DiskAccessProbe` trait」**——决策 250 刚删掉一条只有一处 `impl` 的假 seam
- [x] 缺授权时节点组装**立刻**返回可操作错误、节点转 `pending`，**且不产生超时记账**（反向断言：日志里不出现该节点的 timeout）
- [x] 错误文案含**「若你刚刚已开启，请重启应用」**，并被断言钉住（快照是启动时刻的，运行中改设置进程不知道）
- [x] 用**启动时记下的快照**判，不在读的那一刻探
