# 06: 未消费待办在对讲台页头常驻可见

**Spec:** `../spec.md`（Implementation Decisions 第 10–11 条）

**What to build:** 作为值班经理，我要在对讲台**页头**看到一条只读读数：现在有几条待办没被消费、分别是哪几类。
它必须**在值守轮排队期间也存在**——这次那两条待办挂了 2 小时 26 分没人消费，而我在页面上什么都看不见。

**Blocked by:** None (can start immediately)

**Status:** done（已实现，决策 302–311；四门 `make check` 全绿）

- [x] 新增一个**只读**计数端点：未消费待办条数 + 类别摘要（计数 SQL 已在，缺的是读取端点）；端点形状与既有只读端点同族，走 `api_contract` 那套断言
- [x] 页头**新增一枚独立只读 span**；**反向断言**：值守轮未在跑时这枚读数**仍在**——**明确不并进那枚「值守台账 · 正在跑」的 crumb**（它的判据是「值守轮在飞」，而本场景值守轮**正在排队**，`in_flight = false`，crumb 根本不出现：最需要看见的那一刻它不在）
- [x] **渲染条件**：有未消费待办时渲染（含值守轮排队期间）；**0 条时不渲染**（省窄档空间）——这条要写进决策，别当默认值含糊过去
