# 05: 审计、口径与保留期

**What to build:** 每一轮对话都留得下**「谁说的、依据什么」**——你说的话、值班长的话、它当时
看到的态势快照、它调用过的工具痕迹。对讲台自己报「本次会话 N tok」，而**全局流水线指标不因
闲聊变化**；过期的对话按既有保留口径自动清理。

**Blocked by:** 02（工具痕迹要有工具才存在）

**Status:** ready-for-agent

- [ ] 每轮落库：该轮注入的态势快照 + 该轮的工具痕迹
- [ ] 对讲台自报「本次会话 N tok」（由落库的 token 列求和）——成本可见
- [ ] 全局指标不因对话变化：断言对话前后 `total_tokens` / `total_calls` 不变
- [ ] 全局指标的**口径注释改正**为「流水线执行 + 伪阶段，不含面向人的对话」——项目分析的运行行
      今天是**计入**全局指标的，原注释「流水线执行」四个字与事实已经对不上，这次一并说清
- [ ] 保留期接进**既有的会话清理作业**，与既有保留天数同口径（对讲台不做全仓唯一不设保留期的表）
- [ ] 测试：假时钟推进到期后行被清理（等不了真实 30 天）
