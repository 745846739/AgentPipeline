# 04: 版面三分区——急停钉在第一屏

**What to build:** 对讲台按**三层内容各有归属**重新排：上半是第一屏**钉死**的**状态区**
（当前急停 + 值班板），下半是**对话时间线**（值班长的话、值班员的话），工位回执留在对话里；
输入坞钉底。**对话滚到很长之后，急停仍然可见**。

**Blocked by:** 01（需要有能对话的工头）

> 注意：03 与本票都改对话区的标记，先做哪个都行，但两张票不要在同一个工作区并行改同一片。

**Status:** ready-for-agent

- [ ] 状态区（急停轮 + 值班板）不随时间线滚动；一个两小时前挂起的急停滚出视野是本页最不能出的错
- [ ] 值班长的话与值班员的话只差**名牌停靠与明暗档**，不换底色、不换圆角、不加箭头；不做左右
      交替的气泡
- [ ] 工位回执用**左缘亮度阶 + 无框**，形状上就与发言不同；引用工位结论时标出来源工位
- [ ] **值班长的回复里永远没有按钮**——写动作只在状态区的急停轮里渲染（同一动作在两处各渲染
      一颗钮，会让「哪个是真的」变成使用者必须思考的问题）
- [ ] 值班长**不占琥珀档**；全站唯一的响仍只在急停一处
- [ ] 空态的「去看板新建任务」是页面固定的**导航钮**，**不进入**后端动作契约
- [ ] 窄屏：输入坞钉底、值班板收成横向灯条、状态区仍在对话之上
- [ ] 新 CSS 不含 token 块外裸色值（浅色派生脚本的完备性校验仍通过）
- [ ] e2e：把对话滚到很长之后急停仍可见；值班长的回复里查不到动作钮
