# 01: 打通最小对话路径——空 home 也能跟值班长说上一句

**What to build:** 值班员在一台全新机器上（没有项目、没有任务）打开对讲台，在输入坞里打字发送，
得到值班长**基于夜班态势快照**的一句回话；这句话落库，刷新页面后还在。对话从这一刻起不再依赖
任何任务的存在——「没有任务在跑」不再是「没话可说」。

这是本 effort 的示踪弹：它穿过的层次最全（表 → 存储 → 工头模块 → 端点 → 前端 → e2e），
后续每一票都在这条通了的路上加厚，而不是另起一条。

**Blocked by:** None（可立即开始）
