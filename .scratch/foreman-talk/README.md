## 切片理由

**01 是示踪弹**——一条穿到底的窄路（表 → 存储 → 工头模块 → 端点 → 前端 → e2e），
先证明「空 home 也能跟值班长说上一句」这条路是通的。02–05 都在这条通了的路上加厚，
而不是另起一条。**06 是前置改动**（「先把改动变简单，再做简单的改动」）：它不交付用户可见行为，
只让 07 判定得了「仅回环可读」，单独一张是因为它会波及所有既有测试。

**没有宽重构票**：本 effort 唯一触及全局的改动是给服务加一层来源地址，而它不需要
expand–contract 序（旧形态没有调用点需要迁移）。

## 关键结论

- **工头不新增阶段枚举变体**，只占第 4 个配置 key——阶段枚举是公开契约（落库列 / SSE 载荷 /
  前端联合类型），且流水线图遍历「全部阶段」这个定长数组，加变体要么静默漏掉、要么把工头
  当成流水线的一个阶段去建节点连边。
- **值班长只说话，不按按钮**：写动作一律由后端下发、由你按下，它的回复里永远没有按钮。
- **对话不计入全局指标**；口径注释一并改正（项目分析的运行行今天是计入的，原注释与事实已不符）。
- **三处待点头项未点头前不建议开工 01**：见 `design.md` §4。
