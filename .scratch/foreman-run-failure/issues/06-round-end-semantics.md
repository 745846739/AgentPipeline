# 06: 一轮的收尾语义三件（轮数设置项 / 触顶部分结论落库 / 悬空提议失效）

**What to build:**
① `FOREMAN_MAX_ROUNDS` 从常量改成**设置项**（住 `stage_configs` 的 `foreman` 行，新增字段），
**缺省 300**；**只允许正整数**——`0` / 空 / `null` 都不许，**不提供无上限**（决策 233① / 239，
**修订决策 224** 的「不把轮数做成阶段配置项」与那个 30）；
② 触到上限**不再整轮作废**：把已确定的部分落库并标注「未收口，以下是已确定的」（决策 233②）；
③ 一轮死了之后，它那一轮提的提议**随之失效**（不再 `pending`）（决策 233③）。

**为什么②是重点**：实测里最贵的一次浪费就是「那 30 轮其实查到了东西（两条提议为证），
却把已经付过钱的结论整段扔掉」——只剩一条 `model_no_reply` 的 system 行与 HTTP 500。

**Blocked by:** None（与其余都不冲突）

**Status:** done

- [x] 用例：触顶那一轮的结论在库里 / 标注在场；悬空提议失效且界面不再给按键；

**Notes（实现提示）:**

  抬墙钟另立一条（决策 233 的如实记 (i)）。
- 收尾这一票是三条一起：②把结论留下、③把没人等的提议作废，都是「一轮死了」的善后。
