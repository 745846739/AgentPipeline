# 值守轮失败的退避与留痕（watch-failure-quiet）

**状态（2026-09-25）：已裁（决策 271），四张票同批落地。**

用户诉求原文（2026-09-25，对讲台截图）：「对讲台一直在报：发送失败
【没跑起来】这一轮没跑起来（llm_network）：连不上 provider：请检查 base_url 是否正确、
网络是否可达（原文：HTTP 请求失败：error sending request for url (http://127.0.0.1:8787/v1/chat/completions)）」

**这批要补的差距一句话**：provider 断供 6 分钟，对讲台多了 **37 行**一模一样的失败账——
失败轮**不消费**待办（对，这条不能改）+ 值守轮**每 10 秒**重试 + 失败**不计入**每小时唤醒上限，
三条叠起来就是一台闹钟；而它的闹铃还顶着「发送失败」那块名牌，读起来像是值班经理自己发的消息
发不出去。
