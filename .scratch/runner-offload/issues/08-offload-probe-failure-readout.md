# 08: 设置页外发探测带出「最近一次外发链路失败」读数

**What to build:** 票 06 验收的第三处留痕(当时显式声明未做,立此票承接):
外发**链路**失败(推分支/dispatch/轮询超时/拉日志失败——注意不含远端命令本身
跑红)回退本机时,除 WARN + 回执文本外,设置页的「重活外发」探测读数也要显红,
让「外发在静默降级」这件事在设置界面上看得见(与决策 185/297 的活体探测同姿态)。

**Blocked by:** 06(工具本体已落地,失败点已知)

**Status:** ready-for-agent

- 建议形状:`kanban_offload` 表加 `last_failure_at`(或独立小表),`offload_run`
  链路失败回退的 WARN 点顺带落一笔;`GET /offload` 探测端点带出该读数;
  `SettingsTools` 卡片上「最近一次链路失败: …」显红,干净跑一轮即清。
- 验收:
  - [ ] 链路失败(假 gh 测试缝即可)后,探测读数带出失败时间;回执文本不变
  - [ ] 外发成功后读数清空;从没失败过的机器上读数为「无」而非「0」
  - [ ] 远端命令跑红(conclusion=failure)**不**计链路失败(与决策 381 的语义边界一致)
