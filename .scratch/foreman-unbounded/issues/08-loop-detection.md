## Comments

- 来源：拷问 Q8、Q16 与裁决 8。全仓今天**没有任何**同参重复 / 无进展检测；唯一的护栏是流式文本的尾部重复（`degeneration.rs`），而且它命中之后值班长那侧没有重试、直接落一条「没跑起来」。
- **实现者记事（提醒不落库）**：上面那一条勾的是「提醒是以带标记 user 轮注入的、进得了模型上下文」，**落库那一半有意没做**——理由写在 `FOREMAN_LOOP_REMINDER_MARK` 的文档里（`crates/core/src/pipeline/foreman.rs`）：落库的 user 行是值班经理说的话，系统提醒写进去会让时间线上凭空多一句「他说过的话」（前端只看角色，分不开）。它在系统里留下的证据是 `tracing::warn!` 那一条与这一轮 `traces` 里那串重复调用本身；真收口时另有收口行上的 `【未收口·在打转】` 与写明的原因。要改回「落库可审计」得先给 user 行一个「这不是人说的」的表达（新列或新角色），那是一处数据模型改动，不在本票。阈值标定现场：真实台账 22 轮 / 359 次调用，最长同参连续 = 1。
