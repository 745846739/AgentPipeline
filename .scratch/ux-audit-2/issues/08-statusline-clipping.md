# 08: 状态行在 480–748px 不再静默裁切

**叠:** A（不动规格；档位取舍与票 07 对齐）

**来源:** R2-10（实测）

**What to build:** 状态行是单行 flex + `white-space:nowrap`，既无 `flex-wrap` 也无 `overflow`，
唯一的适配是 479px 以下隐藏若干格。实测 480–748 之间内容被裁掉且**没有横滚**：

```
w=768 clipped=0
w=700 clipped=48     clockRight=748 > viewport=700
w=600 clipped=148
w=480 clipped=268    clockRight=748 > viewport=480
w=430 clipped=0      ← 移动款变体接管
```

也就是时钟整块、主题钮的一部分在这整段里**静默消失**（组件注释自己记着这个失败模式与
501px 的实测值，但只把下限设在 479、没管中间段）。

**Blocked by:** 07（档位取舍要与中间断点一致，避免两处阈值打架）

**Status:** open

- [ ] 480–748 档：状态行内容不越出视口（折行 / 可滚 / 按优先级舍格，按票 07 的裁决）
- [ ] 被舍掉的格不能是唯一入口（深浅切换在任一档都必须可达）
- [ ] e2e：在 1440 / 1024 / 768 / 700 / 600 / 520 / 480 逐档断言
      `statusline.scrollWidth <= clientWidth`（即无静默裁切）
- [ ] e2e：在 500 与 600 宽按得到深浅切换，断言主题真的变了

**边界.** 不要动 479px 以下既有的移动款变体行为。
