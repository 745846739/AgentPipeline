# 01: 修出口回环谓词（决策 246 落地）

**What to build:** 默认空 allowlist 下，工具层出口（决策 179）的回环豁免只对**真正的本机地址**生效：以 `127.` 开头但不是 IP 字面量的外部主机名（`127.evil.test`、`127.0.0.1.evil.test`，DNS 可解析到攻击者自己的机器）不再拿到放行，照常被拒**且落 `kanban_node_commands`**——审计面看得见「有过一次被拒的出口尝试」（决策 179④）。谓词语义收窄为决策 246 定的规范形态：**归一（去空白 / 转小写 / 去一个尾点 / 脱方括号）→ 能 `parse::<IpAddr>` 就走 `is_loopback()` → 否则判 `localhost`**。这笔是安全语义变更，独立成票、独立提交，可单独回滚。
