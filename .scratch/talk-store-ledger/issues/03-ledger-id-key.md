# 03: 在飞轮改键 ledger_id，折叠态搬运机整段删除

**What to build:** 决策 354③——在飞轮保留 `'live'` 临时键（乐观段，尚无任何可折叠内容），
**首条带 `ledger_id` 的事件到达即改用 `m<ledger_id>` 且此后恒定到收口**。经事实核实
（2026-09-30）：切换点在首条事件，彼时思考体尚未渲染、不存在用户折叠态可丢；
mergeLive 路径（talkTurns.ts:482）本就用 `m<base.id>`，两路键形归一。
`carryLiveStepOpen` / `carryLiveTurnOpen` / `settlingTurn` / 组件搬运 effect 四件删除。

**Blocked by:** 01, 02

**注记（留给后来者）**：

- ① **键的判据只有一处、且不接收参数**：`liveTurnKey(base, events)` 是模块私有函数，
  页面与 store 都碰不到它——`buildTurns` 那一个调用点就是全部。刻意不从外面塞一个
  「当前轮是谁」进来：能塞就等于允许键与数据分叉。
- ② **快照那条半截行优先于事件**：两者说的是同一条行（后端收口写的是同一行，
  `registry.rs::LiveTurn::close`），但快照在手时它更权威（事件可能一条都还没到）。
  这一支与 mergeLive 原本的键逐字一致——本票只是把**另一条路**（本机发送、无快照）
  也归到同一个键形上。
- ③ **老后端 / 流水线事件仍落到 `'live'`**：事件不带 `ledger_id` 时没有行 id 可用，
  与从前逐字一致（那时也没有可折叠内容会丢——它连半截行都没有）。**一处如实记的差别**：
  若真有那么一条「不带 `ledger_id` 却攒出了步骤」的路，收口时那点展开态不再被搬
  （搬运机没有了），会退回「人点开的块自己合上」。本仓到不了这条——工头的增量与工具
  事件都带位置戳（`LiveTurn::begin` 在模型循环之前建行），流水线事件又被班次守卫挡掉
  ——故这是一条**够不着的**差别，不构成回归；写在这里是为了不把「逐字一致」说满。
- ④ **为什么换键不丢人的操作**（票面「经事实核实」的落点）：乐观段一个步骤都没有，
  所以 `live-s<i>` 从来没进过折叠表；首条事件那一刻渲染出来的步骤键**从一开始**就是
  `m9-s0`。这一条写成了单测（「换键瞬间没有可折叠内容」），不是只写在注释里。
- ⑤ **必须补的那道守卫：同一轮只摆一遍**（原票面没写、e2e 闸门逼出来的）。
  两态同键带来一个票面没预见的形状——**收口那一拍两条都在**：`sendTurn` 里
  `reload` 已经把落地那一行写进 `session`（并 `await loadAttention()`），而
  `settleTurn` 要等 `reload` 返回才倒空现场；这一拍 `base` 已是 null（行不再是
  `in_flight`）而事件仍攥着 `ledger_id`，于是时间线里**同一轮摆成两条、渲染键都是
  `m<id>`**。`Talk.svelte` 的 `{#each turns as turn (turn.key)}` 对同键**抛错**
  （`svelte.dev/e/each_key_duplicate`，生产构建也抛）——首轮全量 e2e 10 条红，
  全部红在这一个错上。修法只一句：`out` 里已经有这个键那一行时在飞轮整条退场
  （台账那一行是权威，在飞轮只是上一个时态的残影）——与 `syncFollowing` 那条
  「尾巴是上一轮的残渣，台账那一行会把它接住」同一条纪律，只是判在渲染上、早一拍。
  这条守卫顺带修好了**中断行**那一支（重启恢复标完终态之后同样只摆台账那一条，
  决策 312 的口径）。单测两条钉住它（收口那一拍只出一条 `m9`、中断行同理）。
- ⑥ **删掉的是实现，不是行为**：决策 301 的口径（碰过的永不被自动打回、没碰过的
  本来就默认收起）一个字没动——那两条 e2e 因此**不需要改一行**，它们钉的正是行为。
  决策 301 行与 315 行各加了一处「实现层修订」标记。
- ⑦ **反向牙齿跟着判据走**（`delegation-scan.test.ts` 新增一组）：搬运机三件在
  页面 / store / 模块三处都不许再出现；页面那一对暂存（`liveSeen` / `liveSid`）也不许
  回来。**票 02 记的那条「已知边界」随本票消失**：那处 `liveSid !== untrack(...)` 的
  误伤面没了，故把页面的反向扫描放宽到 `/sessionId\s*!==/` 的全部（原先只钉
  `talk.sessionId !==` 一种拼法）。
