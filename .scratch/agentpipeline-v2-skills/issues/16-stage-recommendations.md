# 16: 阶段推荐与一键安装

**What to build:** 设置页按阶段显示**推荐技能**清单，点一次「安装」就把推荐技能装好并写进该阶段配置。
用户可停用推荐、可换成自己想用的任何技能。

**推荐清单的投递载体是界面，不是二进制**（选型「不内嵌」的落点）：以代码内常量形式存在
（沿用决策 7 的内嵌 persona 先例的「内嵌默认值」姿态），界面据此展示。

**Blocked by:** 11（装前预览与信任——一键安装不得绕过信任确认）、15（阶段配置界面——推荐清单长在它上面）

**Status:** ready-for-agent

- [ ] 每个阶段有一份推荐技能清单（代码内常量：阶段 → 推荐技能名 + 推荐理由）
- [ ] 界面显示推荐清单，未安装的项带「安装」按钮，已安装的可直接启用
- [ ] 一键安装：装技能到技能根 + 写入该阶段配置行（`PUT /stage-configs`）一步完成
- [ ] 一键安装**经过票 11 的预览**（不得绕过信任确认；未信任技能不得以全文模式写入）
- [ ] 停用推荐 = 从配置行移除；替换 = 装同名技能到技能根（同名覆盖）
- [ ] 推荐清单里的技能**不存在时界面降级**（显示「未安装」而非报错崩溃）
- [ ] 契约用例：推荐清单返回 / 一键安装写入配置 / 未信任技能不可全文写入 / 停用后配置行移除

**Notes（实现提示）:**
- 推荐清单的内容由实现时决定，但**必须避开默认不该常驻的技能**：上游 27 个技能中有 14 个带
  `disable-model-invocation`（手动触发型），把它们当常驻知识推荐给阶段是错的。推荐应偏向
  「无子代理依赖、无 Skill 工具死指针」的技能。
- 一键安装的失败要可归因（技能不存在 / 摘要不符 / 来源未放行 / 结构非法），不得只给「安装失败」。
