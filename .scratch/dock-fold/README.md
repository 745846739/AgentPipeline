# dock-fold：手机 pending 动作坞默认收成一行

用户报（2026-09-25）：看板任务 pending 时，手机端查看任务详情被 pending 界面挡了大半。

根因：窄屏（<480px）档案盒转成固定底部动作坞后，说明、诊断、动作、触发节点、
文件链接全住在坞里（`.dock` 上限 72vh）——human_review / 暂停这类带 textarea 与
多颗 48px 钮的坞实测可占四到六成屏，小屏过半；详情正文只剩上面一条缝。

裁决（决策 281）：常驻的是**一行手柄**（「⏸ 等你拍板 · {label}」+ ▲ 闪烁光标），
点开才是完整动作面；说明与动作全量保留在展开层，异步按钮点击即禁用、坞钉在
`--sbar-h` 上沿的让位口径不变。
