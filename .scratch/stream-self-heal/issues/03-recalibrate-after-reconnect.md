# 03: 接回必校准:主动重连置「断过线」+ 对讲台接校准回调

**What to build:** 两个「重连成功但内容不恢复」的缺口,一次修掉。其一,解锁竞态:可见性恢复触发的校准请求与重连是并发的,若校准因网络未醒先失败、重连却成功,系统认为「没有错过」,断流期间的阶段迁移停在旧画面,要等下一条事件或手动刷新才补上——修法是**任何主动重连一律置「断过线」标记**,重连成功后必补一次全量校准,可见性回调里那次并发校准降级为「先到的预热」(重复校准无害,失败的那次有人接)。其二,对讲台的流因非可见性原因断线重连后从不 reload,必须切走再切回来才对齐——把它的校准回调接到**既有的 reload 入口**(与可见性恢复分支同一入口),不新造第二条读路径。

**Blocked by:** None (can start immediately)

**Status:** done（已实现）

- [ ] 单测:主动重连(重置退避、立即重开那条路径)成功后,校准回调被调用——现状该路径不置标记,这条是红变绿的钉子
- [ ] 单测:错误断线(非主动中断)重连后的既有校准行为不回归
- [ ] 可见性恢复时那次并发校准保留:两处校准并存,重复校准无害
- [ ] 对讲台的流构造传入校准回调,落到它既有的 reload 入口;重连成功后 reload 请求发出
- [ ] 既有连接层单测一条不红
