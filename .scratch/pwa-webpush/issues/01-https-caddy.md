# 01: HTTPS 地基（mkcert + Caddy + 拆明文）

**What to build:** 106 服务器上应用的所有访问走 HTTPS：开发机用 mkcert 生成根 CA（私钥永不上传服务器），签一张含 `106.12.12.6` IP SAN 的长效证书，证书/私钥上机由 Caddy 静态加载并反代 443；后端只绑回环，明文 `http://IP:3333` 入口拆除。装了 CA 描述文件的设备打开 `https://106.12.12.6` 与今天一样使用应用；本机 localhost 开发零变化。运维文档（签发/上机/重签命令）与部署 skill 同步更新，下一次部署不会把明文入口装回来。

**Blocked by:** None (can start immediately)
