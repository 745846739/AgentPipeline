# 前端像素主题替换（agentpipeline-pixel-theme）

**Status:** ready-for-agent

来源：2026-09-13 用户诉求「把本项目前端替换成像素主题」。规格见 [spec.md](spec.md)。

素材已在仓库中（`design/theme-6-pixel.md` + 四份 `prototype-pixel*.html`），本 effort 把它
从**提案**落成**唯一现行视觉**，并让主题三「终端 · 调度电报」退役为历史。

## 范围一句话

交互与信息架构一律不动（路由、五页签、`allowed_actions` 纯渲染、决策 69/79/84/92/101/105/107），
只替换视觉语言，加上承载像素语汇所需的表现层新元素（sprite / 量表 / 横幅 / 道具栏槽位）。

## 已确认的四个选型

| # | 决策 |
|---|---|
| A | **完整对齐原型**——含 sprite、挥锤小人、token HP 量表、boss 尝试条、道具栏槽位、急停 RPG 对话框、完成横幅 |
| B | **主题三退役为历史**——移入 `design/deprecated/`，深/浅双色变体保留 |
| C | **单接缝 + 两层现有验证**——新增主题契约模块；验证复用 vitest 与既有 playwright harness |
| D | **字体自托管入库**——缝合像素 12px 的 78 个 woff2 子集（~860KB）内嵌单二进制，离线可用 |

## 执行注意

- **既有 e2e 断言由弄坏它的那张票一并修**，不留到最后——否则中间提交是红的：
  02 改琥珀计算色、04 改 `*N` 计数、05 改 `[dev]`/`[test]` 分支标签、06 改页签文本；
  12 做全量核对与收尾。**一律改成断言同一行为的新表达，不得删断言。**
- 主题三 token 删除在 02（那才使应用变像素），但**文件归档在 13**——搬家与链接追逐只在
  无代码改动时做一次。
- 提交前闸门 = `make check`（lint + test + frontend + e2e，决策 168），既有 96 vitest +
  17 playwright 必须全绿，用例数只增不减。

## 关键约束（与既有决策的关系）

- 与既有决策冲突必须显式标注编号（AGENTS.md）。已知需标注处：
  - **决策 84**——分支消歧由 `[dev]`/`[tst]` 文字标签改为徽章色相（蓝 / 紫 + 文字双编码）；
    语义与逐游标动作集下发不变，变更的只是视觉手段（票 01 登记、票 05 落实）。
  - **决策 143**——可测试性接缝表增第 5 条「主题契约」（票 13 落文档）。
  - **决策 156 / 168**——字体入库致 `dist` 与 dmg 增大约 0.9MB（票 01 登记）。
- 图元只允许来自受控 sprite 表，动画预算只有四处（链节步进 / ▼ 光标 / 方块光标 / 小人挥锤）；
  新增一律回 `theme-6-pixel.md` 修订后实现。
- 仍是 480px 单断点；不新增平板/中间断点；不改任何后端端点。
