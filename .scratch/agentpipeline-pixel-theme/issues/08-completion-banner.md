# 08: 任务完成横幅

**What to build:** 任务跑完时有明确的收束而不是一行灰字：顶部居中弹出奖杯横幅——奖杯 sprite +
「任务完成」+ diff 摘要（如 `+542 −13`）+ 「收下」按钮。它不自动消失、不自动滑入，用户点「收下」
才关闭，所以不会在读完之前溜走。

**Blocked by:** 03 全站像素控件与基元

**Status:** ready-for-agent

- [ ] 任务进入 done 时顶部居中弹出**任务完成横幅**：trophy sprite + 「任务完成」+ diff 摘要
      + 「收下」按钮；**无入场动画**（像素纪律：禁止淡入滑入）；点「收下」关闭
- [ ] diff 摘要的数据来源沿用既有前端解析（`DiffStats` 由 diff 文本机械解析，API 无
      stage_outputs 读取端点）；**摘要不可得时不假装有数字**——只显示标题与「已合入」，
      不画 0 冒充真实值（与指标页缺数据同一姿态）
- [ ] 横幅与既有 toast 并存且不互相遮挡：两者都是 fixed 定位，需给出确定的层叠与位置关系
      （toast 仍在右下，横幅居中于顶部）；`aria-live` 与可访问名齐备
- [ ] 任务不是 done（failed / cancelled）时不显示横幅；失败/取消的既有终态提示保留
- [ ] 横幅本身不触发重复弹出（同任务同一次 done 只弹一次；刷新后不再重弹）
- [ ] 底部看板条的 token 总量与横幅不冲突；`prefers-reduced-motion` 下行为一致（本来无动画）
- [ ] vitest 补：done 时横幅出现且含 diff 摘要；点「收下」后消失；摘要缺失时不渲染 0
- [ ] 既有 vitest / playwright 全绿
