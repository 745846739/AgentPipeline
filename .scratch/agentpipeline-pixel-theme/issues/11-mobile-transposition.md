# 11: 移动版五条转写

**What to build:** 手机上看板不是把桌面压窄，而是把**横向传送带竖过来**：屏幕一个方向只放一站，
轨道变成纵向链节脊线；道具栏横滚；待审批时恢复动作沉到常驻底部动作坞；挥锤小人挂在站头；
页面导航与顶栏同 sticky。做完后手机上从看板到决策到台账全是同一套像素语汇。

**Blocked by:** 05 看板传送带与货箱、06 详情 hero 与页签、07 急停对话框与工头头像、
08 任务完成横幅、09 台账页、10 指标页
