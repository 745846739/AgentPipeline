# 09: 台账页（项目 / 模型与密钥 / 手机访问）

**What to build:** 三个设置类页面不再是「另一个应用」：与看板同一套 2px 描边盒与硬投影，
页头有返回看板的面包屑与 24px 标题，导入语是弱灰提示行，记录排成台账行（行首名称亮纸白、
副值灰、末列动作钮）。三处的既有防御行为一条都不能丢（vendor 降级、密钥掩码、二维码白底）。
