# 06: 归档班次翻得回——chip 行开关 + 只读打开

**What to build:** 班次 chip 行有一个「显示已归档」开关；打开后归档过的班次以灰 chip
出现在列表里，点开是只读时间线，能看到它的全部消息内容（不提供续聊、不提供恢复归档）。
关掉开关回到现状。值守台账同样可用。

**Blocked by:** None (can start immediately)

**Status:** done（已实现，决策 312，票 01–07 同批落地）

- [x] chip 行「显示已归档」开关；归档班次渲染为灰 chip，与活跃班次一眼可辨
- [x] 打开归档班次是只读时间线：消息内容完整可读，没有输入坞/续聊/恢复归档的入口
