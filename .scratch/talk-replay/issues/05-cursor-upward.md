# 05: 会话内更早消息向上游标加载

**What to build:** 单个班次超过 500 条时，滚动到顶自动加载更早的消息，阅读位置不跳；
500 条以内时行为与现在完全一致（一次加载、直接滚动、零额外请求）。「更早的看不见」
不在会话内部复现。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [x] 会话消息读接口保留「最近 500 条」缺省语义，新增 `before_id` 游标：按行 id
      返回更早的一段，段内升序
- [x] 前端滚到顶触发加载，已读位置保持、已加载的消息不重不漏
- [x] 500 条以内的会话：加载路径与现状一致（不新增请求）
- [x] 契约用例：缺省 500、游标分段正确、到头返回空
- [x] 显式标注修订后端读接口「不分页」的产品立场（→ 500 缺省 + 向上游标）
