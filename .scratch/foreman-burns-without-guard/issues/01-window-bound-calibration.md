# 01: 窗口界同批校准——真实窗口值 + 加权估算 + 撞墙自校准

**Spec:** `../spec.md`（Implementation Decisions 第 1–2 条）

**What to build:** 作为值班经理，我要「轮内压缩的触发线」**真的落在真实窗口的 80%**。
今天它两边都错、而且**偶然抵消**：触发线 = 0.8 × 配置窗口 128,000 ≈ 102,400「估算 token」，
而估算对中文低估 **≥ 5.5 倍**、配置对真实窗口低 **≥ 4.5 倍**，于是这条线实际落在约 56 万真实 token——
正好压在真实窗口边缘：95 轮**一次都没触发**，真触发也已经太晚。
**两处必须同批生效**：只修窗口 → 线抬到数百万真实 token 永不触发；只修估算 → 线掉到真实窗口的 18%，每轮都压、缓存全废。
