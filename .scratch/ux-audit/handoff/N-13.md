# N → 编排者（票 13 / §三.3 空态语汇）：`talk.spec.ts` 里那条「去看板新建任务」是钮还是路

**口径来源（照抄别改）**：`parallel-brief.md` §三.3（空态统一用 `<EmptyState>`：状态 → 下一步 → 可选入口，
**凡是提到另一个页面，必须可点**）；票 `.scratch/ux-audit/issues/13-empty-states.md`；
`frontend/src/components/ui/EmptyState.svelte` 的 props（`state` / `next?` / `href?` / `linkLabel?`）。

---

## 目标文件：`frontend/e2e/talk.spec.ts`（无主，请编排者转交）

**要什么**：第 649–654 行那一处，把

```ts
const navBtn = page.getByRole('button', { name: '去看板新建任务' });
await expect(navBtn).toBeVisible();
await expect(page.locator('.zone-status .turn button')).toHaveCount(0);
```

改成按**链接**断言（`EmptyState` 的入口是一个 `<a href>`，不是 `<button>`）：

```ts
const navLink = page.getByRole('link', { name: '去看板新建任务' });
await expect(navLink).toBeVisible();
await expect(navLink).toHaveAttribute('href', '#/');
// 空态里没有后端下发的动作钮（这一条不变：动作集纯粹是后端的事，空态不假装有动作）
await expect(page.locator('.zone-status .turn button')).toHaveCount(0);
```

第 649–651 行的注释（「空态的『去看板新建任务』是**页面固定的导航钮**」）请一并改成
「页面固定的**导航入口**（`EmptyState` 的可选入口，纯前端路由，不进后端动作契约）」。

**为什么**：票 13 要求七处空态（含对讲台）统一用 `<EmptyState>`，它的入口是链接；
对讲台的状态区空态因此从「一行文字 + 一颗 `<button>`」变成
`EmptyState(state="当前没有急停。", next="…", href="#/", linkLabel="去看板新建任务")`。
**用户可见行为一个字没变**（点它照样落看板，且它仍然不是后端下发的动作），
变的只是这一处的元素角色（button → link），旧断言按角色取元素会打红。

`EmptyState.svelte` 是编排者的文件，不新增 props、不改形状；改动只落在对讲台的调用点上
（`frontend/src/routes/Talk.svelte`，N 名下，已落地）。
