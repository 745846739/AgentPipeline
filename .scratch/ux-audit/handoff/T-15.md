# T → 编排者（票 15 / 决策 195 §2.6）：`.svelte` 文件里用错档的 `--text-4` 逐处归位

**为什么走 handoff**

票 15 的「用错档的地方逐处归位」里，落在 `.svelte` 组件里的那些**不在 T 名下**
（`parallel-brief.md` §一.1 / §二：组件归各页所有者）。T 已把 `app.css` 里属于 T 的那两处改完
（`.input::placeholder`、移动款 `.cmd-l1`，见汇报），并把 token 值提上去（`--text-3`
深 `#8E8CA5` / 浅 `#636477`），但**组件里的 token 用法**要由各页所有者改。

判据（`design/theme-6-pixel.md` §2.6 用法职责第 1 条，照抄）：
**读不到就会挡住下一步的 → `--text-3`；纯刻度装饰 → 才留 `--text-4`。**
`--text-4` 的合法用法只剩结构噪声（未来站名 / 回流带 `↩` / 空刻度槽）。
改法只许改**用的 token**，不许写死颜色值。
