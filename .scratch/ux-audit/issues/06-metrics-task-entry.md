# 06: 指标页的任务级入口不再要求手打 ULID

**叠:** A（不动规格）

**What to build:** 想看某个任务的指标，现在必须在指标页下半段**手打一个 ULID**——没有选择器、
没有最近任务、也没有从任务详情跳过来的链接。改成任务详情上有一个到「这个任务的指标」的入口，
点了直接落在该任务的指标视图。

**Blocked by:** None（can start immediately）

**Status:** done
