# 18: 决策：脊线上那个数字的口径补定义

**叠:** B-决策（一票只回答「怎么定」；本票不动任何代码）

**What to build:** 脊线在站名下显示一个数字，列头也显示一个数字，两者长得一模一样
（都是「站名 + 小方框里的数」）但量不同：脊线是**累计到过这一站**的人数（漏斗），
列头是**此刻停在这一列**的人数（存量）——同一时刻实测相差一倍。规格从没定义过脊线
这个数字的口径，所以这是**补定义**，不是修 bug。这一票只回答「怎么定」：口径留哪个、
在界面上怎么区分。

**Blocked by:** None（can start immediately）

**Status:** done

- [ ] 定下同屏出现时如何不让人误认为同一个量
- [ ] 追加修订决策并在规格里记录这个口径（原先从未定义）
- [ ] 定下并行分支那两处站名的层叠处置：**站名被传送带压穿是原型继承的几何、不是实现回归**，
