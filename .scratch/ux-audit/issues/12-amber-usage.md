## 01 的判定（逐处，2026-09-16）

依据（规格位置一律引 `git show HEAD:design/theme-6-pixel.md`，即本轮修订前的原文；
工作树里这份规格正被 DEC-VIS 改，行号已位移，按小节名去对更稳）：
`:47`「琥珀仍是全站唯一告警」；`:79`／`:153` token 表把用途枚举成「等拍板、stalled、待办计数」；
`:251`「`! 不受支持 · 决策 103` **琥珀标**」（行内降级）；`:254`「`mdot` 灯与 `fill` 条同色
（go / **caution** / stop / done / dev / test）」；`:256`「`gate` 指引块」。
全文「阶段配置 / 推荐技能 / 未安装 / warnnote / 入口闸」**0 命中**。

| 处 | 判定 | 处置 | 依据与实测 |
|---|---|---|---|
| 指标页「各阶段重试率」的方块标记 + 横条 | 规格**允许**灯色，但规格内部冲突 | **让灯色随值取**（0 → 中性档；>0 才 `caution`）。**不能只改灯**：灯与条同色是 `:254` 的硬要求，动的是 `tone`（`lib/metrics.ts:108` 的 `tone:'caution' as const` 让整张图恒为告警色） | 实测 `.mdot` border `rgb(255,181,69)`、`.fill` 同色，而同列数值是 `0.0%`；对照同屏「平均耗时」`.mdot` = `rgb(78,84,120)`。本条**不违反 `:254`**，只需在 `:254` 补一句「灯色随值取」；若改成整图中性档则属改明文，须追加修订标注 |
| 推荐技能「未安装」 | 规格**没说**（0 命中）+ 语用上是默认态（12 行里常驻 12 枚） | **回中性档**（`--text-3`，与票 15 的「次级必读」同口径） | 实测 color `rgb(255,181,69)`；已装态是 `--done`。没有明文允许它，「琥珀 = 全站唯一告警」是明文 |
| 「阶段配置区标题」 | **原稿这一处不成立** | 不动标题；这一块真正的琥珀是「整条替换」**题注** `.replace-note` → **保留琥珀** | 实测 `.sub-head h2`「阶段配置」= `rgb(241,236,220)` = `--text-hi`（原型 `prototype-pixel.html:478` 同款）；`.replace-note` 文字与 2px 框才是 `rgb(255,181,69)`。题注是「动手前必须知道的后果」，与 `.warn` 风险提示同类 |
| 告警注记 `.warnnote` | 规格**明文允许** | **保留并写下依据**；顺手订正 `app.css:520` 的注释 | `:251` 明文「琥珀标」；实测只在「不受支持 vendor」那一行渲染。注释写「不受支持说明 / **删除拒绝原因**」，而删除拒绝原因实际走 `.reg-err`（`--stop` 红） |
| 手机访问页入口闸标题 `.gate-head` | 规格**没说色**（`:256` 只写了块） | 闸标题**回中性亮档**；同页 `.warn`（⚠ 开放局域网前确认网段可信）**保留琥珀** | 实测闸标题 `rgb(255,181,69)`。闸标题说的是「拿不到什么 + 按哪颗钮」，不是一件待你处理的事；`.warn` 要人拍板 → 是 |
