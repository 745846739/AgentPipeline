# 02: 三个模态框一起修：Escape 能关、焦点进得去也出不来、能被人读屏播报

**叠:** A（不动规格）

**What to build:** 新建任务、拆任务、覆盖模型这三个对话框是同一份复制粘贴的写法，毛病也一样。
实测（审计里的键盘可达性用例）：点开「新建任务」后按 Escape，**对话框仍然开着**——因为 Escape
挂在遮罩上，而焦点还在背后的「新建任务」按钮上，从来没进过对话框；键盘还能一路 Tab 到弹窗
背后的页面。三个一起改成：打开时焦点落在第一个输入框、Escape 一律可关、焦点关在框内、
对话框本身带可被播报的模态语义。

**Blocked by:** None（can start immediately）

**Status:** done

- [x] 点开任一对话框后焦点就在第一个输入框里，不需要先点一下
- [x] 焦点从未进过对话框时按 Escape 也能关掉（不是只有焦点在框内才关得掉）
- [x] Tab / Shift+Tab 在对话框内循环，不会跑到背后的页面上
- [x] 对话框在无障碍树上是一个有名字的模态，读屏会播报「进了一个对话框」
- [x] 鼠标行为不变：点遮罩、点取消都还能关
- [x] 三个对话框各有一条 e2e：开 → 断言焦点位置 → Escape → 断言已关；并断言 Tab 不逃逸
