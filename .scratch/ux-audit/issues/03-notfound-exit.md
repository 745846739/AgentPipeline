# 03: 404 页给一条回看板的路

**叠:** A（不动规格）

**What to build:** 走进不存在的地址时，整页只剩左上角一行 12px 灰字「页面不存在：/nope」，
没有返回、没有看板入口（只有顶栏还在）。而且那段文案把地址里恒有的 `#` 也带进了正文。
改成：说清状态 + 一条回看板的路，文案里出现的地址是干净的路由名。

**Blocked by:** None（can start immediately）

**Status:** done

- [ ] 访问不存在的路由时，页面上有一处可点的回看板入口，点了落在看板
- [ ] 文案里出现的地址不带 `#` 前缀
- [ ] 这一页用与其它空态同一套语汇（状态 → 下一步 → 入口），不是孤例
- [ ] e2e：直接打开一个不存在的路由 → 断言入口存在 → 点击 → 断言落在看板
