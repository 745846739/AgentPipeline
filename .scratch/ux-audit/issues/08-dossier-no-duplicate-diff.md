# 08: 拍板时不再在同一屏渲染两份同样的 diff

**叠:** A（不动规格）

**What to build:** 任务卡在等人合入时，主区 Diff 页签渲染一份 diff，右栏档案盒再渲染一份，
于是同一份 diff（同一对「返回修改 / 合入」）在同一屏出现两次，「哪个是真的」变成使用者
必须思考的问题——而「合入」是全站最重要的一颗按钮。档案盒的存在理由是「不切页签也能拍板」；
当用户已经在 Diff 页签里时，右栏应该收成一个不重复内容的状态摘要。

**Blocked by:** None（can start immediately）——但**动作行是红线**，见下

**Status:** done

- [x] 停在 Diff 页签时，屏上只有一份 diff 内容（档案盒里不再出现第二份）
- [x] **档案盒的动作行（返回修改 / 合入）始终在**：六个 e2e 文件里的多处定位依赖它，
      它是被测合约的一部分，不是冗余。去掉重复只能去 diff 面板那一份
- [x] 不在 Diff 页签时，档案盒的内嵌 diff 仍按原样出现（这是既定设计，不动）
- [x] 移动款的底部动作坞不受影响
- [x] e2e：停在 Diff 页签 → 断言 diff 只出现一次、动作行仍在 → 切到别的页签 → 断言档案盒内嵌 diff 回来
