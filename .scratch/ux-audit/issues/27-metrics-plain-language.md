# 27: 指标页第一段改成说人话，未知的比值说清为什么

**叠:** A（不动规格）

**What to build:** 指标页第一段现在是数据库与状态机层的词汇，摆在页面最上方、用最暗的一档灰排版：
「统计口径见 core metrics（决策 130 / 137）：成功率 = done ÷（done+failed+cancelled）；
重试率 = attempt > 1 的 run 占比；逃逸事件 = trigger = kickback 的流转数；
首过率 = validate_output 首次 attempt 即通过的比例。共 3 个任务…`total_tokens` 1,275 ·
`calls` 34」；页脚还有一句带编号的说明。改成说人话：每个数是什么、怎么算、看它该得出什么结论，
原始字段名换成平实说法。另外成功率在分母为 0 时只显示一个「—」，读者分不清是坏了还是本来
就没有意义——改成说清原因。

**来源：** 审计报告的这一条在同日重看截图时被**缩小过**：原稿说「比例类的图没有数值」，
实际每列都带数值，唯一的横线是分母为 0 的成功率。所以本票是「说人话 + 横线给理由」，
不是「补数值」。

**Blocked by:** None（can start immediately）。**与 23 共用这一段文字**：编号的去除归 23，
本票负责整段的重写。谁先落地谁就把这一段写成人话且不带编号，另一票落地时不要回退。
