- 页头在 `≤899px` 收成一行：`<h1>` visual-hidden、行内容 = 当前班次名（截断）· 值班中 · 本次会话 N tok · 看板 + 右端 ⋯；行**做成 46px 的钉住带子**（44px 行 + 2px 下框）钉在 `top: var(--topbar-h)`，`.talk` 的间距从统一 `gap` 改成逐块外边距（页头→状态区那一对归 0）。

**审查后补（2026-09-18，决策 222）**：本票要求的「在 `#/talk` 上点第 1 格灯 → 落到 `#/` 且 `#s-init` 进视野、改址是路由跳转不是整页刷新」补齐了——一补就红：`jumpToStation` 里的 `await tick()` 抓不到 `hashchange` 之后才发生的渲染（实测整页 `scrollTop` 停在 0、目标在视口下方 1027px）。根因在 `router.navigate` 只写地址栏、组件读的镜像要等 `hashchange`；修法见决策 222。另：本票在组件媒体块里写的 `:global(body) { padding-bottom: var(--sbar-h) }` 是**全站**的（Svelte 组件样式不隔离），会把 480–899 上所有页面的底盘边距一起改掉——已改成在**本页内部**读这两份数（`min-height` 减 `--sbar-h` + 一条抵掉 8px 差额的负外边距；减 46 会让坞悬空 10px，全量 e2e 会红），不动 `body`。
