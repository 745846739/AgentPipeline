## 1. 设计概念

**一句话：** 流水线总图是一张正在晒制中的工程蓝图——整屏是一号图纸，任务是图上的部件，
评审 pending 是"待签章"，打回是红章退图。

领域词汇在此主题的转译：看板 = **图幅（一张图框内的图纸）**，任务 = **件号（明细表条目）**，
尝试次数 = **版次（REV A/B/C）**，审批 = **签署**，指标 = **尺寸标注**，产出文件 = **白纸贴图**。

四条原则：

1. **两墨一警示。** 晒图蓝底上只有白（制图墨）与青（结构线）两色墨，加琥珀（pending）
   与印红（失败·退回章）两个警示色；没有第三种装饰色。无渐变、无投影、无发光。
2. **线型即状态。** 实线 = 已完成，粗白线 = 执行中，虚线 = 未开始，点划线 = 并行分岔中心线，
   带箭头虚线 = 折返。状态优先走线型与字形（✓ ● ○ ⏸ ✗ ↩），颜色只作第二编码——
   对色弱用户最友好的款（决策 84 的分支消歧 = dev 实线双轨 / test 虚线双轨 + `D`/`T` callout）。
3. **图纸要能签。** 每个任务有自己的件号；详情页右下图签（title block：图号/图名/版次/日期）；
   pending = 待签章，动作按钮 = 签署动作（核准 / 退回并附意见），文案全站用"签"字系。
4. **格网恒在但不管事。** 8px 晒图格网以 5% 白衬在一切之下，只提供"图纸感"；
   布局对齐仍走 4px 栅格，格网不参与吸附。

## 2. Design Tokens

### 2.1 色彩

| Token | 值 | 语义 |
|---|---|---|
| `--bg` | `#123A63` | 深晒图蓝，页面底色 |
| `--panel` | `#17426E` | 明细表面板 / 图签底 |
| `--grid` | `rgba(255,255,255,.05)` | 8px 晒图格网 |
| `--line` | `rgba(242,247,252,.30)` | 图框线、卡片描边 |
| `--line-soft` | `rgba(242,247,252,.14)` | 轨道暗段、弱分隔 |
| `--text-hi` | `#F2F7FC` | 制图白墨：标题、执行中（对底 ≥ 11:1） |
| `--text-2` | `#BBD4EC` | 正文（≥ 8:1） |
| `--text-3` | `#8FB3D9` | 次文本、标注（≥ 5:1） |
| `--go` | `#F2F7FC` | running：**粗白实线 + 白针点**（无绿色；蓝图上"绿"不存在） |
| `--pending` | `#FFC53D` | pending / stalled 琥珀（≥ 8:1，全站唯一告警） |
| `--stop` | `#FF7A6B` | failed / 退回印红（≥ 5:1） |
| `--done` | `#BBD4EC` 60% | done 退后 |
| `--paper` | `#F7FAFD` | 贴图：diff 与代码块渲染在白底"贴图"上（唯一白底例外） |
| `--diff-add` / bg | `#1B6B40` / `#E7F4EC` | 贴图内增行（沿用极简主题已验证色对） |
| `--diff-del` / bg | `#99332B` / `#FAECEA` | 贴图内删行 |

**规则：** 蓝底区域只用白/青/琥珀/印红；白纸贴图区域沿用极简主题的 diff 与代码配色。
分支（决策 84）：develop-design = 实线双轨 + callout `D`；test-design = 虚线双轨 + callout `T`。

### 2.2 字体

| 角色 | 字体 | 用法 |
|---|---|---|
| UI / 标注 / 标题 | Chakra Petch（400/500/600/700） | 方形制图气质；中文回退 PingFang SC |
| 件号 / 尺寸 / ID / diff | IBM Plex Mono（400/500） | 只给可执行物（命令、路径、diff、ID、token 数）——不变量 |

字阶：10 / 11 / 12（基准）/ 13 / 15 / 18 / 24。callout 与图签字段名允许 10px 全大写 +
0.1em 间隔（制图标注惯例，仅限这两处，不作全站眉标）。

### 2.3 形状与密度

- 圆角 0（制图无圆角）；无投影；选中态 = 外扩 2px 第二道描边（双线框 = 选中，制图惯例）。
- 看板列宽 280px，列间 12px；详情内容区最宽 1040px，右下图签固定。
- 卡片 = **明细表行块**：白描边 0 圆角面板，四角画小十字定位标（角标 6px，5% 白，
  纯装饰但强化图纸感）。

### 2.4 动效

- 唯一主动效：首载**晒图显影**——整屏内容自 40% 不透明度 + 4px 青色偏移在 500ms 内
  显影到位（模拟蓝图水洗），一次性编排，不做逐卡入场。
- 响应式动效：节点完成时该段线"描深"（细→粗 200ms）；pending 时「待签」章 180ms 落章
  （scale 1.15→1）；折返弧点亮为印红箭头；流式输出尾随 ▊（决策 123）。
- `prefers-reduced-motion` 全部关闭。

## 5. 主题特有细节

- **件号章**：卡片左上角 mono 件号（`t-0042`）是本主题的身份记号；看板列内按件号排序可选。
- **版次 = 尝试**：`validate_attempts` 渲染为 REV A/B/C…；时间线里 retry 行同时标注版次变化
  （对齐决策 80 的游标模型与 glossary 的 ExecutionState）。
- **尺寸线指标**：全局指标页（frontend-design.md §7）的轨道分段条形图在本主题下
  升级为真尺寸标注（界线 + 箭头 + 数字置于线上方）。
- **callout 纪律**：全大写微标只允许出现在站点 callout 与图签字段名两处，其余文案一律短句。

## 6. 无障碍与实现注记

- 对比度：正文 ≥ 8:1，次文本 ≥ 5:1（见 §2.1）；状态主要靠线型 + 字形（✓ ● ○ ⏸ ✗ ↩），
  颜色为第二编码——五款中对色弱用户最稳。
- Token 变量与 frontend-design.md §3 语义命名对齐；主题落地 = token 文件 + 三处组件级覆盖
  （格网底、贴图反白区、图签块）。
- 字体经 CDN（Chakra Petch / IBM Plex Mono）；`prefers-color-scheme` 不做暗色变体
  （蓝图本体即深色）；决策 16 技术栈不变。
- 原型：[deprecated/prototype-blueprint.html](deprecated/prototype-blueprint.html)（与既有两款同一套三视图；
  支持 `#v-board` / `#v-run` / `#v-approve` hash 直达）。

## 7. 何时选它

想要"总览像一张总图"的仪式感；对外演示/汇报时记忆点最强；线型双编码对色弱最友好。
代价：整屏高饱和蓝，长时间盯屏的舒适度低于夜间调度台与极简时刻表。
