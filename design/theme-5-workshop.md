> 第五套视觉语言。页面元素与 [deprecated/prototype.html](deprecated/prototype.html) / [deprecated/prototype-minimal.html](deprecated/prototype-minimal.html)（已归档）

## 1. 设计概念

**一句话：** 开发者是车间主任，看板是车间墙上挂工单的告示板——任务是打印出来的工单，
状态是盖章，pending 是插在「等你拍板」格里的橙色急件。

领域词汇在此主题的转译：任务 = **工单（一张纸）**，列 = **挂单格**，轨道 = **车间传送轨道**，
状态 = **章**（运行中 / 等拍板 / 已终止 / 已归档），pending = **急件**，dossier = **急件夹**。

四条原则：

1. **印刷品，不是软件。** 卡片是纸（纯白），墙是灰（冷灰白）；层级只靠**硬投影**
   （3px 3px 0 纯黑 offset），没有玻璃、渐变、柔影。hover/按压 = 纸被按到墙上（位移消影）。
2. **黑描边纪律。** 一切可交互物 2px 纯黑描边；全站表面只有墙灰、纸白、纯黑三阶，
   状态色只以**实心色块**出现（章、左缘条、计数圆章），永不作大面积底色；
   警示斜纹只允许出现在急件夹顶缘一处。
3. **大字报数字。** 时长、token、计数用超大黑体数字，是页面的视觉主角；
   文案仍是短句，按钮写动作（合入 / 退回 / 补充说明并继续），状态章写结果（运行中 / 等拍板 / 已终止）。
4. **章不过三。** 一张工单上最多一枚状态章 + 一条左缘色条；决策 84 的分支消歧 =
   双药丸各带 `D-`/`T-` 前缀徽章（蓝 / 紫），徽章色不作状态语义。

## 2. Design Tokens

### 2.1 色彩

| Token | 值 | 语义 |
|---|---|---|
| `--bg` | `#E9EBE8` | 车间墙，冷灰白（刻意避开暖奶油底） |
| `--paper` | `#FFFFFF` | 工单纸面 |
| `--ink` | `#101114` | 纯黑：描边、正文、投影（对墙 ≥ 14:1） |
| `--text-2` | `#4A4F55` | 次文本（≥ 7:1） |
| `--text-3` | `#7A8087` | 弱文本、占位（≥ 4.5:1）；done 的退后灰 |
| `--go` | `#2F9E44` | 信号绿章「运行中」（章上白字仅用于 ≥ 18px 粗体） |
| `--pending` | `#F59F00` | 安全琥珀：急件章「等拍板」、计数圆章（配黑字 ≥ 8:1，全站唯一告警） |
| `--stop` | `#E03131` | 记号红章「已终止」、退回、破坏性动作 |
| `--branch-dev` | `#1971C2` | develop-design 徽章蓝（仅徽章，不作状态） |
| `--branch-test` | `#6741D9` | test-design 徽章紫（同上） |
| `--hazard` | 8px 45° 斜纹 | `--pending`/透明 相间；仅急件夹顶缘一处 |
| `--diff-add` / bg | `#1B6B40` / `#E9F3EC` | 纸上印刷绿（沿用极简主题色对） |
| `--diff-del` / bg | `#99332B` / `#FAECEA` | 纸上印刷红 |

**规则：** 一张卡 = 一枚章 + 一条缘；queued / waiting 无章灰字。投影 `3px 3px 0 var(--ink)`，
按压态 `translate(2px,2px)` + 1px 投影——位移量即层级反馈，不引入第二套阴影。

### 2.2 字体

| 角色 | 字体 | 用法 |
|---|---|---|
| 展示：wordmark / 列头 / 大数字 | Anton（400） | 海报体；中文回退系统粗黑（PingFang SC Semibold） |
| 正文 / UI | Archivo（400/500/600） | 13–14px 基准，行高 1.55 |
| 可执行物 | Space Mono（400/700） | 命令、路径、diff、工单号、token 数——不变量 |

字阶：11 / 12 / 13（基准）/ 15 / 18 / 24 / 34（大数字 34 起步，配 11px 灰注）。
数字全部 tabular-nums。

### 2.3 形状与密度

- 圆角仅 2px（防"印刷毛边"的极小倒角）与 0 两档；无柔影。
- 看板列宽 280px，列间 16px；卡片内距 16px——密度比极简主题略低（纸面要有呼吸），
  大数字补足信息效率。
- 列头 = 黑底白字条（印刷条块），高 32px，直角。

### 2.4 动效

- **无入场动效**（纸早就贴在墙上了）；非用户触发的动效只保留一处：急件计数圆章 2.4s 呼吸。
- 响应式动效：盖章（scale 1.2→1 + rotate -6°，180ms，状态变化时）；按压位移（hover 1px /
  active 2px）；SSE 状态迁移时旧章淡出新章落章（决策 76 事件驱动）。
- `prefers-reduced-motion` 全部关闭（落章直接切结果态）。

| 会话查看器 | 纸面对话：角色名 = 小黑章（SYSTEM/USER/AGENT）；工具调用 = 黑框纸条（mono 函数名 + 绿 ✓ 结果）；流式尾随 ▊（决策 123） |

## 5. 主题特有细节

- **章的词汇表**（全站统一，动作与章同名呼应）：运行中 / 等拍板 / 已终止 / 已归档 / 已合入；
  对应按钮：继续 / 补充说明并继续 / 重试（回到 init）/ 审核并合入 / 返回修改。
- **大数字的边界**：只有时长、token、计数三种量用 Anton 34px；标题、正文永不用展示体。
- **投影即交互**：能按的都投影，不能按的都不投影——投影是 affordance，不是装饰。
- **急件夹唯一性**：斜纹全站仅 dossier 顶缘一处；若一屏多 pending，仍只有计数圆章呼吸。

## 6. 无障碍与实现注记

- 对比度：黑/墙 ≥ 14:1，次文本 ≥ 7:1，弱文本 ≥ 4.5:1；琥珀章黑字 ≥ 8:1，
  绿/红章白字仅用于 ≥ 18px 粗体（大文本 3:1 达标）。
- 状态除色块外均有章上文字（运行中/等拍板/已终止）与左缘双编码；分支有 `D-`/`T-` 文字前缀。
- Token 变量与 frontend-design.md §3 语义命名对齐；主题落地 = token 文件 +
  两处组件级覆盖（硬投影工具类、黑条列头）；决策 16 技术栈不变。
- 高对比、强投影是刻意取舍：适合团队大屏与演示，不适合长时间凝视——
  这是它作为候选三之一的存在理由，不是缺陷。
- 原型：[deprecated/prototype-workshop.html](deprecated/prototype-workshop.html)（与既有两款同一套三视图；
  支持 `#v-board` / `#v-run` / `#v-approve` hash 直达）。

## 7. 何时选它

团队共用大屏、需要"一屏镇住"的演示场景；情绪价值与记忆点最高；
键盘党与副屏长挂场景不如终端款，克制控不如极简款。
