# 主题三 · 终端「调度电报」

> 状态：深色 / 浅色桌面款 + 深色 / 浅色移动款均已产出（2026-09-12）。
> 交互与信息架构一律沿用 [frontend-design.md](frontend-design.md)（路由、五页签、待办 dossier、
> `allowed_actions` 纯渲染（决策 69/101）、异步按钮、卡片禁拖）；本文只定义该交互骨架上的
> 第三套视觉语言。页面元素与 [deprecated/prototype.html](deprecated/prototype.html) / [deprecated/prototype-minimal.html](deprecated/prototype-minimal.html)（已归档）
> 同一套（8 列看板、详情三视图、顶栏过滤、demo 切换器）；sync-check 全站不展示（决策 107）。

## 1. 设计概念

**一句话：** 把看板当作一台仍在值班的调度电报终端——没有"界面"，只有一份被流水线不断改写的电文。
列车位置、折返、待办，全部以字符电文的形式拍给你。

领域词汇在此主题的转译：看板 = **窗格（pane）阵列**（tmux 布局），任务 = **电文（一条条文本记录）**，
顶栏/底栏 = **状态行（status line）**，轨道 = **字符线路行**，pending = **慢速反白的告警行**。

四条原则：

1. **一切皆文本。** 结构靠字符与亮度，不靠盒子与图标。没有装饰图形：站点是 `●/◆/○`，
   状态是 `[RUN]/[WAIT]/[FAIL]` 文字标记，轨道是线段字符。字符记号永远与颜色双编码
   （色弱可用，决策 84 的分支消歧同样靠 `[dev]/[tst]` 文字标签而非色相）。
2. **单色磷光阶梯。** 全站只有绿磷光的一串亮度阶；琥珀（pending）与红（失败）是仅有的两个
   状态例外色，没有第三种装饰色。不是"黑底 + 一个绿 accent"，而是整个表面都泡在磷光里。
3. **键盘优先。** 每个动作都有键位；过滤、跨列、进详情、dossier 动作全部可键盘完成，
   ⌘K 命令面板是一等入口。鼠标完整可用，键盘是渐进增强。
4. **层级靠亮度，不靠字体。** 与"等宽只给可执行物"（frontend-design.md §2 原则 4）的偏离
   在此显式声明：本主题全站等宽（这是主题的特权），"可执行物"转译为**亮度提升 + 反白**；
   命令、路径、diff、ID、token 数仍以更高一档亮度呈现，从不弱于正文。

## 2. Design Tokens

### 2.1 色彩

| Token | 值 | 语义 |
|---|---|---|
| `--bg` | `#0A0F0B` | 磷光黑绿，页面底色 |
| `--panel` | `#0D130F` | 窗格底 / hover 行底 |
| `--pane-line` | `#23392B` | 窗格 1px 框线 |
| `--hairline` | `#16241B` | 弱分隔、电文行分隔 |
| `--text-hi` | `#D6F2DC` | 亮磷光：标题、当前游标、可执行物 |
| `--text` | `#A6D8B2` | 正文（对底 ≥ 10:1） |
| `--text-2` | `#6FA481` | 次文本（≥ 5:1） |
| `--text-3` | `#5E9673` | 弱文本、列头、站点标签（≥ 4.5:1） |
| `--text-4` | `#49775A` | 占位/装饰刻度，不承载必读信息 |
| `--go` | `#8FF0A8` | running：**反白底色**（配 `#07120A` 前景） |
| `--pending` | `#FFB454` | pending / stalled（琥珀磷光，全站唯一告警） |
| `--stop` | `#FF7A70` | failed / 打回 / 破坏性动作 |
| `--done` | 同 `--text-2` | done 刻意退后 |
| `--diff-add` / bg | `#6FE08F` / `#0F2417` | diff 增行（前缀 `+` 双编码） |
| `--diff-del` / bg | `#FF8A7A` / `#2A1414` | diff 删行（前缀 `−` 双编码） |

**规则：** 一张电文行上最多一种状态例外色；分支（develop-design / test-design）**不用色**，
用 `[dev]` / `[tst]` 标签（决策 84）。queued / waiting 落在 `--text-3` 灰绿。

### 2.2 字体

| 角色 | 字体 | 用法 |
|---|---|---|
| 全站唯一字体 | Fira Code（400/500/600，`calt` 关闭） | 中文回退 PingFang SC；数字 tabular-nums |
| 状态标记 / 列头 | 同上，600 + 全大写 + 0.08em 间隔 | `[RUN]` `[WAIT]` `[FAIL]` `[DONE]`、列头 |

字阶：11 / 12 / 13（基准）/ 15 / 18。层级靠亮度阶与字重，不设第二字体。
连字全站关闭：命令与 diff 必须逐字符可读。

### 2.3 形状与密度

- 圆角 0（绝对）；无投影；无描边盒——唯一的"框"是窗格 1px 单线。
- 看板列宽 264px，列间即窗格共享框线（双列贴线，无间隙）；详情内容区最宽 960px。
- 电文行高 1.6，基准字号 12.5px，密度比既有两主题再高一档（行距收紧、meta 并行排布）。

### 2.4 动效

- **无任何入场动效**（电文即刻呈现，比极简主题更激进）。
- 响应式动效仅三处：流式输出尾随方块光标 `▊`（500ms 闪，决策 123 流式渲染）；
  pending 行慢速反白呼吸（2.4s，亮度 0.85↔1.0）；节点完成时该行一次 120ms 反白闪作确认。
- `prefers-reduced-motion` 全部关闭；按钮点击即 `[ … ]` 文案 + 禁用，SSE 回执复位。

### 2.5 浅色变体「绿杠电报纸」

**一句话：** 浅色款不是把磷光反相，而是换一种材料——同一份调度电文，打印在连行**绿杠打印纸**上。
绿杠（line-printer green bar）与磷光是同一条计算血缘：纸张被规则横杠分成条带，
**横杠即轨道**，报头字段压在杠上。

三条换译规则：

1. **层级靠墨度，不靠亮度。** 深色款是"越亮越重要"，浅色款是**越深越重要**：
   同一串语义 token（`--text-hi` → `--text-4`）翻成一个从墨黑到淡灰绿的墨度阶梯。
2. **横杠即结构。** 全站只有三条绿杠，都对应真实结构——轨道区间、看板列头（报头字段条）、
   底部状态行（撕纸汇总条）；不刷装饰性斑马纹。移动版把绿杠竖过来用：站段脊线 = 竖向绿杠。
3. **形状、动效、字符记号一律不换。** 圆角 0、无投影、字符站点（`●/◆/○`）、
   `[RUN]/[WAIT]/[FAIL]` 文字标记、括号按钮与深色款逐字一致——变体只换表面材料。

| Token | 值 | 语义 |
|---|---|---|
| `--bg` | `#F1F5EE` | 纸白（极淡青绿，不是暖米白） |
| `--panel` | `#DDE9D9` | 绿杠底色：轨道带 / 列头带 / 底栏 / 面板 |
| `--wash` | `#D6E4D2` | 交互态 hover / 按压（比绿杠再深一档 = 更多墨） |
| `--pane` | `#A9C0A4` | 窗格 1px 框线（对纸 1.77，对齐深色款框线比例） |
| `--hairline` | `#D7E2D3` | 弱分隔、电文行分隔（对纸 1.21） |
| `--text-hi` | `#0C1F14` | 墨黑：标题、当前游标、可执行物（15.6:1） |
| `--text` | `#23402E` | 正文（10.3:1） |
| `--text-2` | `#47614F` | 次文本（6.2:1） |
| `--text-3` | `#4C6656` | 弱文本、列头、站点标签（5.7:1；在绿杠上 5.0:1） |
| `--text-4` | `#6C8173` | 装饰刻度（3.79:1，对齐深色款 3.75:1） |
| `--go` | `#1E6B41` | running：**实心墨绿块**（配纸白前景 5.9:1） |
| `--go-hi` | `#175633` | 主动作 hover 加深 |
| `--pending` | `#8C5A0A` | pending / stalled（焦琥珀墨，全站唯一告警） |
| `--stop` | `#A32A1F` | failed / 打回 / 破坏性动作（赭红墨） |
| `--diff-add` / bg | `#1D6A3C` / `#DEEDDD` | diff 增行（前缀 `+` 双编码） |
| `--diff-del` / bg | `#9E2A1E` / `#F6E0DC` | diff 删行（前缀 `−` 双编码） |

移动版追加脊线三态 `--spin` / `--spin-lit` / `--spin-pen` = `#CFE0CA` / `#5E9370` / `#B3812F`：
脊线是 3px 竖杠，比深色款的 1px 细线浅一档，以保持同等视觉重量。

**组件级覆盖只有四处**（其余规则与深色款逐条相同）：`--panel` 作底的轨道带（背景渐变，
桌面 `.railwrap` / `.hrail`，移动 `.bar-top` / `.sec-head` / `.carrier` / `.dock`）、
列头带、底栏、以及站点侧标签遮罩底色由 `--bg` 改为 `--panel`。
线路三档（`--br` / `--br-done` / `--lit` / `--dash`）只为在纸上重新标定深浅。

**对比度注记：** 深色款 `--text-4` 对底 3.75:1、`--hairline` 1.20、脊线 1.56；
浅色款按同一比例标定（3.79 / 1.21 / 1.25），而非机械反相——浅端人眼灵敏度下降，
线性反相会让计数与时间戳（`--text-4`）掉到 2.4:1 而不可读。

## 6. 无障碍与实现注记

- 对比度：正文 ≥ 10:1，次文本 ≥ 5:1，弱文本 ≥ 4.5:1（见 §2.1）；`--text-4` 只用于装饰刻度。
- 状态三色均带文字标记（`[RUN]/[WAIT]/[FAIL]`），分支带 `[dev]/[tst]`——不依赖色相（决策 84 同源）。
- Token 变量与 frontend-design.md §3 的语义命名对齐（`--bg/--panel/--text-hi/--signal-*`）；
  主题落地 = 新增一份 token 文件 + 三处组件级覆盖（窗格框线、反白药丸、状态行）。
- 字体经 CDN 引入（`Fira Code`），完整系统回退栈；决策 16 的 Svelte + TS + Vite 不变。
- 原型：深色 [prototype-terminal.html](prototype-terminal.html)、
  浅色 [prototype-terminal-light.html](prototype-terminal-light.html)
  （与既有两款同一套三视图；支持 `#v-board` / `#v-run` / `#v-approve` hash 直达）。
- 移动版见 §8。

## 7. 何时选它

长时挂在副屏、SSH/远程低带宽场景、重度键盘用户；与 IDE / 终端同屏时视觉融合度最高。
代价：气质冷峻，演示场景的记忆点弱于蓝图与车间两款。

## 8. 移动版（深色 / 浅色）

移动版不是把桌面压窄，而是把 tmux **窗格阵列**转写成纵向**电报纸带**：屏幕一个方向只放一列，
轨道从"横向脊线"改为"纵向脊线"。内容与状态标记与桌面逐字相同（9 张任务电文、8 站轨道、
同一套 `[RUN]/[WAIT]/[FAIL]`），只有排布与两个交互件重写。深浅两款共用一份结构，只差 §2.5 的 token。

| 视图 | 结构 |
|---|---|
| 0 电报纸带（看板） | 顶栏状态行（`agentpipeline` + `0:本体` + 轨道缩略条）→ 过滤行（横向滚动）→ 8 段纵向站点带（脊线 + 段头字段条 + 电文行组）→ 底部载波行 |
| 1 待处理 | 按等待时长收拢的收件箱（最久在最上）；此页无脊线，pending 的琥珀左缘在收件语境里补回 |
| 2 详情 · 执行中 | 标题行 + meta → 纵向轨道 hero（8 站）→ 分段页签（时间线 / 会话 / 命令与输出 / 产出文件）→ 内容 |
| 3 详情 · 待审批 | 纵向轨道 hero → 待办块 → Diff 页签 → **常驻底部动作坞** |

四条移动专属转写：

1. **轨道缩略条。** 桌面顶栏那条 2154px 线路压成 8 个字符站点；点击跳段，
   滚动时用 `IntersectionObserver` 反亮当前段并以 `▾` 指位。
2. **段头即字段条。** 桌面的窗格顶边（列头）成为段头（`INIT` / `ARCHITECT-DESIGN` …），
   浅色款下正是纸上绿杠的位置。
3. **pending 动作坞。** dossier 在窄屏无法常驻右侧，改成固定底部动作坞，进入 pending 任务时出现；
   动作同样走异步按钮（点击即 `[ … 合入中 ]` + 禁用，回执后替换为完成行并撤下动作坞）。
4. **命令表两行制。** 桌面单行多列（状态 / 时间 / 来源 / 命令 / 耗时 / 退出码）在窄屏折成两行：
   上行元信息，下行命令本体（不截断、可换行）；Diff 保持单行不折、横向滚动。

触控与无障碍：可点目标 ≥44px 高；输入框 16px（防 iOS 聚焦缩放）；
`safe-area-inset-bottom` 进底栏与动作坞；`prefers-reduced-motion` 关掉全部呼吸与闪烁；
宽屏（≥480px）自动套 430px 手机框居中查看，便于桌面评审。

原型：深色 [prototype-terminal-mobile.html](prototype-terminal-mobile.html)、
浅色 [prototype-terminal-mobile-light.html](prototype-terminal-mobile-light.html)；
支持 `#v-board` / `#v-wait` / `#v-run` / `#v-approve` hash 直达。

**已知缺陷（两款桌面版共同，非浅色引入）：** 详情页 hero 轨道在
`#v-run` / `#v-approve` 下，`architect` 站标签与分岔下轨的 `test-design` 标签重叠
（`.stn.side.dn .lb{right:16px}` 向左越过前一站）。移动版无此问题。
