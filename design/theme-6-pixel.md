## 1. 设计概念

**一句话：** 开发者是深夜车间的工头（玩家），看板是一台还在运转的 8-bit 流水线——
任务是传送带上的货箱，工位是机器，指示灯报告每台机器的状态，pending 是机器急停、
弹出的对话框正在等你按键。

> **「工头」的定义有第二个用法待裁（见 §3.3）。** 本节这句话把工头定为**玩家本人**
> （dossier 那枚头像 = 等你拍板的你）。§3.3 对讲台按用户诉求「和工头对话」把工头摆成
> **对话的另一方**（值班长），且该页面**已实现**。二者不能同时成立，
> **裁决前 §1 的这句话仍以「玩家本人」为准**，§3.3 的措辞按待裁稿读；登记见决策 174。

领域词汇在此主题的转译：任务 = **货箱**，列 = **工位**，轨道 = **传送带**，
状态 = **信号灯**，pending = **急停**，dossier = **操作台对话框**，
折返线 = **回流带**，并行分支 = **双带并轨**。

四条原则：

1. **像素纪律。** 全站唯一字体（缝合像素 12px，见 §2.2），字号只取 12 的整数倍
   （12 / 24 / 36），禁用中间号；圆角恒为 0，描边只有 2px 一档；阴影只能是
   `4px 4px 0` 的硬投影；禁止平滑渐变与柔光——**2×2 棋盘 dithering 是全站唯一的"渐变"**，
   只允许出现在货箱顶盖带与已归档工位两处。
2. **灯即状态。** 沿用全站信号语义（绿 = 执行、琥珀 = 等人、红 = 失败、灰 = 归档、
   蓝 / 紫 = 分支徽章）。灯是实心像素方块，绝不作大面积底色；一张货箱上最多
   一枚灯 + 一种描边色。琥珀仍是全站唯一告警。
3. **急停对话框是主角。** pending 内容渲染成 RPG 对话框（双线框 + ▼ 光标），
   它是全站视觉权重最高、也是唯一"响"的东西；其余一切保持安静。
   boldness 只花在这一处。
4. **帧步进，无缓动。** 一切动画用 `steps()` 离散步进，像素世界的位移不经过中间帧：
   运行中工位的传送带虚线步进、对话框 ▼ 光标与流式输出方块光标闪烁、按钮按压位移。
   `prefers-reduced-motion` 下全部静止。禁止 ease / cubic-bezier 缓动与淡入滑入。

**选型自评（为什么不是那些更省事的像素风）：**
GameBoy DMG 四色绿——与主题三磷光绿同色相，撞车；`Press Start 2P`——像素主题的
默认字体，且无中文；全站 CRT 扫描线 / 玻璃反光——模板装饰，不携带信息；
近纯黑底 + 单酸绿强调——与主题三气质重复。最终选择：夜靛底 + 暖纸白文字 +
中文字体像素化，靠「急停对话框 + 传送带」两个领域转译承载个性。

## 2. Design Tokens

### 2.1 色彩（深色默认「夜班靛」）

| Token | 值 | 语义 |
|---|---|---|
| `--bg` | `#1B1D2C` | 夜班靛，页面底色（不是纯黑，带一点蓝紫的厂房夜灯色温） |
| `--panel` | `#232639` | 货箱面 / 对话框底 / hover 行底 |
| `--wash` | `#2B2F47` | 交互再深一档：active tab、dither 用色 |
| `--pane` | `#3E4363` | 2px 描边、传送带未点亮段 |
| `--ink` | `#12131E` | 硬投影专用墨色（比 bg 深两档，仅作 `4px 4px 0` 投影） |
| `--text-hi` | `#F1ECDC` | 暖纸白：标题、可执行物、当前游标（对 bg ≥ 12:1） |
| `--text` | `#C7C3B4` | 正文 |
| `--text-2` | `#918E9F` | 次文本（≥ 4.5:1） |
| `--text-3` | `#6E6C82` | 弱文本、列头；done 的退后灰 |
| `--text-4` | `#55536B` | 占位 / 装饰刻度，不承载必读信息 |
| `--go` | `#55D97C` | 信号灯绿「执行中」；主动作实心钮 |
| `--go-ink` | `#0B2314` | 实心钮前景 |
| `--pending` | `#FFB545` | 急停琥珀：等拍板、stalled、待办计数（全站唯一告警） |
| `--stop` | `#FF6157` | 失败红：打回、破坏性动作 |
| `--done` | `#6E6C82` | 归档灰，刻意退后 |
| `--branch-dev` | `#59A7FF` | develop-design 徽章蓝（仅徽章，不作状态） |
| `--branch-tst` | `#C08BFF` | test-design 徽章紫（同上） |
| `--diff-add` / bg | `#57D97C` / `#16301F` | 货单印刷绿 |
| `--diff-del` / bg | `#FF7B6E` / `#361A20` | 货单印刷红 |
| `--belt-lit` | `#4E5478` | 传送带已通过段（亮度阶，不用色相） |
| `--dither` | 2×2 棋盘 | `--wash` / 透明 相间，4px 周期 |

**规则：** 一张货箱 = 一枚灯 + 一种描边色（pending 琥珀描边 / failed 红描边 / 其余 pane）；
queued / waiting 无灯灰字。层级只靠硬投影与描边亮度，不引入第二套阴影或柔影。

### 2.2 字体

| 角色 | 字体 | 用法 |
|---|---|---|
| 全站唯一 | 缝合像素 12px 等宽（Fusion Pixel 12px Monospaced，zh_hans + latin） | 标题、正文、数字、命令一律同族；`-webkit-font-smoothing: none` 保脆 |

字阶：**12 / 24 / 36**（12 的整数倍，禁止中间号）。基准 12px 行高 1.6；
工位名 / 列头 12px + `letter-spacing: 0.08em`；大数字（时长、token、计数）24px 起步，
配 12px 灰注；wordmark 24px。禁用粗体模拟层级（像素字体无字重轴），
层级靠字号倍数、亮度阶与描边，`<b>` 仅作亮度提升。

### 2.3 形状与密度

> 以下数值与**冻结原型的实测值**对齐（原稿若与原型不符，以原型为准；逐处对账见 §3.2 末表）。

- 圆角 0；描边 2px 一档；硬投影三处：容器 `4px 4px 0 var(--ink)`、小控件
  `3px 3px 0 var(--ink)`、wordmark 文字 `3px 3px 0 var(--ink)`；按压态为对应距离的
  `translate` + 去投影。
- 货箱顶盖带：6px 高的 2×2 dither 条，是「这东西是实体」的材质提示，每张货箱一条。
- 列宽 264px × 8；详情页 `max-width: 1000px`；dossier 右栏 340px（分栏后整体 1240px）。
- 传送带：**6px 高**，`repeating-linear-gradient(90deg, … 0 6px, transparent 6px 12px)`
  画出像素链节（周期 12px）；运行中工位两侧的链节以 `steps(2)` 步进位移。
- 像素图元：8×8 工位图标（SVG `shape-rendering: crispEdges`，`currentColor` 随列头状态）
  + 16×16 工头头像（琥珀安全帽 + 绿背心，只出现在 dossier 对话框）+ 8×8 挥锤小人双帧
  （抬起 / 落锤+火花）。图元只允许来自本文的 sprite 表，新增图标需回到本文修订。
  **sprite 表**（`prototype-pixel.html` 的 `SPRITES`）：`flag` / `gem` / `hammer` / `flask`
  / `gear` / `lens` / `shield` / `merge` / `trophy` / `chest` / `alert` + 台账页三枚
  `chart`（指标）/ `key`（模型与密钥）/ `phone`（手机访问）+ `foreman`（16×16 工头头像）。
  `foreman` 两处宿主：dossier 对话框（48px，§3.2）与顶栏导航行「对讲台」槽位
  （16px，§3.3——**缩到 chip 节奏**，不是标称的 48px；两处是同一枚图元，不新增 sprite）。
- **列头小人**：每个工位一名，动画速度与颜色随状态——执行中绿锤 0.6s 快挥、
  急停琥珀锤 1.8s 慢挥、空闲 / 排队灰锤静止站立（帧切换为离散 opacity 翻转）。
- token 量表：16 段像素 HP 条（每段 5×10px，间隙 2px），满格 ≈ 64k tok，颜色随状态灯
  （执行绿 / 急停琥珀 / 失败红 / 归档灰）；顶栏底部状态行的「本时辰」总量共用同一量表。
- **boss 战尝试条**：运行中货箱显示当前阶段尝试进度（20 段宽条，`已用尝试 / 上限` 折算
  点亮段数），最后一次尝试时整条转红——只是放大版量表，不引入第二套数据。
- **顶栏道具栏**：过滤项做成 34px 槽位（共享 2px 边框、图标 + 右下角计数徽章，
  hover 出 title 提示）；当前选中槽位 = 亮描边 + wash 底（游戏物品栏选中框）。
- **任务完成横幅**：任务进入 done 时顶部居中弹出奖杯横幅（trophy sprite + 「任务完成」+
  diff 摘要 + 「收下」按钮），无入场动画，点「收下」关闭。
- wordmark：24px + `3px 3px 0 var(--ink)` 硬投影，是全站唯一带投影的文字。

浅色专属偏差（两处，均已验证）：

1. **wordmark 去投影**：硬投影在浅底高对比下会把 24px 紧排像素字搅成重影，
   浅色款 wordmark 无投影，层级由墨色本身承担；
2. **工头头像肤色固定**：脸块不用 `--text-hi`（浅色下变墨块），固定 `#E3C7A6`，
   眼睛保持 `--ink`。

**生成方式（不再手抄）。** 浅色款是深色款的纯 token 变换：头部三行（color-scheme /
标题 / 注释）+ 色彩 token 块 + 上面两处偏差，别无差异。四份文件由
[scripts/derive-light.mjs](../scripts/derive-light.mjs) 从深色款生成，避免手抄漂移
（仓库根执行）：

```bash
node scripts/derive-light.mjs design/prototype-pixel.html        design/prototype-pixel-light.html        desktop
node scripts/derive-light.mjs design/prototype-pixel-mobile.html design/prototype-pixel-mobile-light.html mobile
```

脚本对每处替换都要求命中，否则报错退出（宁可失败也不产出半成品）。**正确性依据**：
用 git 里的旧深色款跑同一脚本，逐字节还原出既有浅色款——变换清单是完备的。
截图由 `.scratch/shots/capture-pixel.mjs` 重新生成（34 张：桌面 8 视图 × 深浅 + 移动 9 视图 × 深浅）。
（§3.3 对讲台加入后由 30 张增至 34 张；四份原型文件同源，浅色款由上面两条命令重生成。）

### 2.5 应用图标（桌面壳 / Dock）

Tauri 壳的图标（`crates/desktop/icons/{icon.png,icon.icns}`，`tauri.conf.json` 的 `bundle.icon`）
也是本主题的一份素材，故纳入本文管辖：**新增/改动图标需回到本节修订**，与 §2.3 的 sprite 表同一条纪律。

**母题**：一只货箱坐在传送带上，右上角一盏绿灯——即 §1 的三个领域转译物
（货箱 = 任务、传送带 = 轨道、灯 = 状态）在同一帧里的最小组合。**图里没有第四个元素**：
没有齿轮、没有箭头、没有字母 A，避免落进「开发者工具 = 齿轮/终端」的通用默认。

**画法**：单份 **32×32 像素母版**（坐标表写在 `scripts/make-icon.mjs`），
各尺寸由它整数倍推导（16px 为 2×2 箱式降采样，其余为最近邻放大）。
像素画的可审查形式是坐标表而非位图——改图改脚本、重跑生成，与 sprite 表同一种做法。

| 元素 | 母版几何（32×32） | 取色 |
|---|---|---|
| 底板 | 内缩 2px 的像素台阶圆角（半径 6px，≈ macOS 0.225 比例） | `--bg` |
| 货箱 | 20×16，居中 | 箱沿 `--belt-lit` / 顶盖带 `--pane` / 箱面 `--wash` |
| 货单标签 | 8×2 一行 | `--text-2` |
| 信号灯 | 6×6，与箱右沿齐平、上半悬出箱顶 2px | `--go`（全图唯一的绿与最亮点） |
| 传送带 | 3 节 × (4px 链 + 4px 隙) = 20px，与货箱等宽对齐 | 已通过 `--belt-lit` / 未点亮 `--pane` |

**两条硬约束**（都不在视觉品味层面，而是正确性层面）：

1. **所有矩形坐标与尺寸必须为偶数。** 16px 由母版 2×2 降采样得到，21 / 17 这类奇数
   会让 2×2 箱跨在图形边缘上，降采样出中间色（既脏又难解释）。`scripts/make-icon.mjs`
   的 `assertEven()` 违反即报错退出；`--dump` 打印 16px 真实位图，可核对「图例里除 token 外
   别无中间色」。另核传送带总宽 = 货箱宽（否则 16px 下两者左右不齐）。
2. **明度序与界面一致，但整体提亮一档。** 界面的货箱面 `--panel` 与底板 `--bg`
   只差一档明度（对比 1.12:1）——32px 尚可，16px 下整只箱子会糊进底板。图标因此取
   `沿 --belt-lit > 盖 --pane > 面 --wash`，即界面 `pane > wash > panel` 同序整体 +1 档。
   **不取暖纸白做箱面**：试过，16px 下箱面成一大块白，反把绿灯的对比吃掉——
   boldness 只花在灯这一处（§1 原则 3）。

**生成与核验**（仓库根执行；无第三方依赖，PNG 由内置 zlib 编码，输出确定性）：

```bash
make icon          # 出 crates/desktop/icons/{icon.png(1024), icon.icns(10 档)}
node scripts/make-icon.mjs --check   # 取色表须与 §2.1 逐字一致，否则报错
node scripts/make-icon.mjs --dump    # 16px 真实位图 + 图例（核像素用）
node scripts/make-icon.mjs --preview # .scratch/shots/icon-preview.png（16/32/256 在深浅两底的放大对照）
```

### 3.3 对讲台（与工头对话）

> **状态：已实现（视觉）；语义前提仍待裁。** 实现落在 `frontend/src/routes/Talk.svelte`，
> 路由 `#/talk`（兼容原型视图 id `#v-talk`），顶栏导航行第 5 个 chip（路由契约见
> `router.svelte.ts`，单测 `router.test.ts`）。**但它带一个尚未裁决的语义前提**——
> §1 现把「工头」定义为**人类开发者本人**（「开发者是深夜车间的工头（玩家）」，dossier 里
> 那枚 48px 头像代表的就是「等你拍板」的此人）。本视图按用户诉求「**和工头对话**」把工头
> 摆成**对话的另一方**，即引入一个值班长角色。**这两者不能同时成立**，故：
> **① 视觉与页面照本文实现；② 工头身份与是否修订 §1，登记在决策 174 待裁**（decisions.md）。
> 另：决策 79 明确 v1 只发布看板、不含对话窗口，本视图因此**在 v1 范围之外**（与决策 50 /
> 附录 B.2 的 v2 对话 agent 同批）；本次是先落页面。
>
> **实现的边界（重要）：本页是「真实状态的对话式视图」，不是可自由对话的 chat。**
> 工头的每句话都由**已有端点的读数确定性拼装**（待办计数、`pending_reason.message`、
> 各 stage 会话的 token 摘要），**没有 LLM 生成、没有编造内容**——因为「会说话的工头」
> 需要人格 + 工具集 + 存储 + 输入端点，那是决策 50 / 附录 B.2 的 v2 专有工作。
> 因此输入口**不做假输入框**：v1 唯一的自由输入仍是 `info_insufficient` 的补充说明
> （决策 79），它作为该轮的 `requires_input` 恢复动作出现在对话框内（`PendingActions`）。
> 数据来源：`board` store（任务与 pending 计数）+ `GET /tasks/{id}`（`allowed_actions` /
> `cursors`）+ `GET /tasks/{id}/conversations`（工位回执读数）。

**实现要点（两处非显然的坑，已修）**：

1. **详情必须随待办集合变化重拉，不能只在 `onMount` 拉一次**——`board.init()` 是异步的
   （`App.svelte` 的 `onMount` 发起），本页 `onMount` 时 `board.tasks` 往往还空着；只拉一次
   会让 `details` 永远为空，页面安静退化成「打开任务详情」按钮，**把后端下发的恢复动作整片
   吞掉**（e2e ⑩ 打红即此）。现以实现 `pendingKey` 指纹（id + pending 类型 + 阶段）驱动
   `$effect` 重拉：集合不变不重拉，一变（装载完成 / resume 后翻转 / `pending_updated` 换理由）才重取。
2. **导航 chip 里的 `foreman` 头像必须缩到 16px**——它的契约显示尺寸是 48px（dossier 用），
   塞进 34px 页签盒会撑到 52px，连带移动端顶栏从 **138px 涨到 156px**，压坏 §5 两处
   148px 定值（`scroll-margin-top` 与横幅 `top`）。已用 `.chip .ic svg.sprite{width:16px}`
   收住，**实测顶栏仍为 138px**（e2e ⑩ 与 ⑨ 各有一条断言钉住）。

**回归门**：`frontend/e2e/talk.spec.ts`（4 条：两种 URL 写法可达 + 顶栏入口图标 16px、
值班板 8 工位、待拍板轮的标题/中文理由/琥珀框/▼/后端下发动作可下发、移动款顶栏 138px）。
另 `router.test.ts` 钉住 `#/talk` 与 `#v-talk` 都解析为 `talk`。

**设计取向：不造聊天组件，把操作台对话框竖起来排。** 全站视觉权重最高的东西是急停对话框
（§1 原则 3），对讲台直接复用它作为发言单元：**压在框沿上的名牌 tab 就是发言者**，故不再
另加一行 `who`，也不做左右交替的气泡。一列对话 = 一叠对话框，身份由名牌承载而非位置。

| 区块 | 实现 | 纪律 |
|---|---|---|
| 发言 `turn` | 挂 `.dialog`（复用双线框 + `.dname` 名牌 tab），只改停靠与留白 | **框色默认收在 `--pane`**：只有待拍板那一轮挂 `.warn` 转琥珀并点亮 ▼ |
| 我（工头本人） | 同一 `.dialog`，名牌 `right:6px` + `--t2` | 明暗区分，不引入第二套色或第二套形状 |
| 工位回执 `rcpt` | 左缘 4px `--pane` 亮度阶 + `--panel` 底，**无框** | 回执是**转述不是发言**：行内 sprite + 工位名 + 状态；与命令输出同一手法 |
| 输入口 `typer` | 对话框形（双线框），描边 `--pane`、名牌收 `--t3` | 主动作交给既有实心 `▶` 钮；不新增动画位 |
| 值班板 `brows` | 右栏 340px，复用台账盒（`.reg` / `reg-head`）+ 8px 信号灯方块 | 桌面 `sticky`；窄屏收成顶栏下横向灯条 `crew` |
| 流式 | 沿用既有方块光标 `.streaming`（▊） | 不新增光标 |
| diff / 产出 | 沿用 `.dfile` / `.dbody` 原语 | 不新造 diff 渲染 |

**四条纪律**（都由「boldness 只花在一处」推出）：

1. **对话是竖排的对话框，不是气泡。** 身份靠名牌，不靠左右位置；故 `turn.mine` 只移动
   名牌并提亮正文，**不换底色、不换圆角、不加箭头**。
2. **全站唯一的响仍只在急停一处。** 待拍板那轮挂 `.warn`（琥珀框 + ▼ + 恢复动作），
   其余轮次一律 `--pane`。对讲台**不新增第二个响点**，也不新增第五个动画位——
   输入口虽有边框但刻意安静。
3. **回执是转述，不是发言。** 工位自述用左缘亮度阶（`.rcpt`），与工头所说的话在形状上
   就不同；工头引用工位结论时，该结论必须标出**来源工位**（像素本身不可考，靠 sprite +
   工位名文字双编码）。
4. **可追溯性不因对话而丢失。** 用户说的话与工头转述的工位结论都进审计；界面上
   「谁说的」永远可见（这是本主题对 §1 原则 2 的延续：不能只有人说，没有状态）。

**与决策 79 的关系（需裁决）**：本视图是**顶层路由级**界面（顶栏导航行第 5 个 chip
「对讲台」，`#/talk`），与看板并列，**在 v1 范围之外**。若裁决改为
「任务详情第六页签」或「升级现有只读会话页签」，本节的视觉语言**不变**，只换宿主
（`Talk.svelte` 的内容整体搬入即可，路由与导航项相应撤下）；
若裁决维持「工头 = 玩家本人」，则本视图降级为「你向整个流水线发话」，`turn.mine` 与
工头发言需合并为同一明暗档，正文措辞同步调整——**实现里 `turn.mine` 目前未使用**
（本页只有工头发言 + 工位回执），故该降级只需改措辞，无需改结构。

## 4. 选型注意

- 与主题三的边界：同为深色，但主题三是「字符终端」（单字族等宽、字符线路行、无盒体），
  本主题是「像素游戏机」（中文像素字体、实体货箱、对话框）；二者不可混用元素——
  字符线路行（○ ● ◆）在本主题内一律替换为像素灯与链节。
- 与主题五的边界：主题五用纸白 + 硬投影印刷隐喻；本主题沿用硬投影手法但材质换成
  像素盒（dither 顶盖、描边亮度阶），且底色为夜靛非墙灰。
- 动画预算全站只有四处（链节步进、▼ 光标、方块光标、列头小人挥锤 / 摆臂），
  帧切换一律为离散 opacity 翻转；任务完成横幅无入场动画。新增动画位需回到本文修订。
  **实现期登记的一处补记**：hero 的当前游标另有「心跳微光」（`heartbeat`，1.2s `steps(2)`，
  §3.2 偏离表第 4 行——原型用灯 + 心跳表达当前游标，取代主题三的滑动圆点 + 柔光）。
  它是同一条「当前游标」动画位的实现形式，不新增第五个语义位。
  「琥珀闪烁」（急停灯 / `.warn-dot` / 待办计数）是同一处「信号灯闪烁」位在各宿主的复用。
